300 − 100 = 0,02g

200 = 0,02g

g = 200/0,02

g = 10.000

30 + 4x = 5x

A: A(10) = 50 + 4(10)

A(10) = 50 + 40 = 90

B: B(10) = 20 + 5(10)

B(10) = 20 + 50 = 70

O B é o mais barato para x = 10

Qual é mais barato para x = 40?

A: A(40) = 50 + 4(40) 

A(40) = 50 + 160

A(40) = 210

B: B(40) = 20 + 5(40) 

B(40) = 20 + 200

B(40) = 220

O A é o mais barato para x = 40
