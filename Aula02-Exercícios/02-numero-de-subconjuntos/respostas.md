# 02 - Número de Subconjuntos

## Enunciado

Em um sistema de banco de dados, você precisa realizar um relatório cruzando
informações de 5 tabelas diferentes (A, B, C, D e E) usando JOINs.
Para garantir que nenhuma intersecção de dados seja deixada de fora durante a modelagem
relacional, responda:

## 1- Qual é o número máximo de subconjuntos disjuntos que podem ser formados pela intersecção dessas 5 tabelas?
**Resposta:**
2⁵ = 32 - 1 = 31 subconjuntos disjuntos


## 2- Se adicionarmos mais uma tabela (totalizando 6), quantos novos subconjuntos exclusivos serão gerados?
**Resposta:**
2⁶ = 64 - 1 = 63 subconjuntos disjuntos, menos os 31 já existentes (63 - 31) teremos 32 novos subconjuntos
