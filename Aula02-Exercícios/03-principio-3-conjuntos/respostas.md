# 03 - O Princípio com 3 Conjuntos

## Enunciado

Um total de 1232 estudantes cursaram Espanhol, 879 cursaram Francês e 114 cursaram Russo.
Além disso, 103 cursaram Espanhol e Francês, 23 cursaram Espanhol e Russo, e 14 cursaram
Francês e Russo. Se 2092 cursaram pelo menos um dos 3 cursos, quantos cursaram os 3 cursos
simultaneamente?

## Resolução

|E ∪ F ∪ R| = |E| + |F| + |R|
             - |E ∩ F| - |E ∩ R| - |F ∩ R|
             + |E ∩ F ∩ R|

Substituindo os valores:

2092 = 1232 + 879 + 114 - 103 - 23 - 14 + x

2092 = 2085 + x

x = 2092 - 2085

x = 7

**Resposta:**
7 estudantes cursaram os três cursos simultaneamente.
